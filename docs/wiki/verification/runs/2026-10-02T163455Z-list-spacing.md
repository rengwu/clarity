# 3 October 2026 — Search and list spacing

## Scope

The user reported the Agent board's search/empty-message crowding and requested similar fixes throughout the app. **FEAT-shared-ui**, **FEAT-agent-board**, **FEAT-notes**, **FEAT-mail** are the changed spacing contracts; other modules are checked for retained presentation. Baseline native inspection measured zero gap on Board and below Notes' root-folder control. Shared list feedback now uses 12px margins; standalone page search fields use the same 12px gap already present in Bookmarks. Mail empty feedback increases from 8px to 12px. Existing toolbar gaps remain 12–16px. Board status precedes its list, including during loading.

The [shared specification](../../foundations/desktop-stack.md#search-and-list-spacing-3-october-2026) owns behavior and the repeatable recipe. This is a focused spacing fix and self-verification, not an independent or exhaustive design audit. No backend, provider, dependency or data change.

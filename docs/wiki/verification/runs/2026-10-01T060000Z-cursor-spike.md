# 1 October 2026 — Cursor Desktop browser spike

## Scope

Verify the **FEAT-shared-ui** experimental [Cursor Desktop spike](../../references/technical-spikes.md#cursor-desktop-design-spike-1-october-2026). The selected journeys exercise sample Chat, Notes, Todos, Wiki and optional Calendar. These outcomes do not certify the production implementations of those modules.

## Build and environment

Node 22.19.0 on macOS arm64, dependency-free external source, loopback server at `http://127.0.0.1:4318`, and Synara's integrated browser. The [source manifest](../../evidence/2026-10-01T060000Z-cursor-spike/build.json) records all six executable-source files and aggregate SHA-256 `369dd12821a5ca93738bd2b68ac250ed7e97a72b465c7fc5cbaa201df72fd025`. The [workspace snapshot](../../evidence/2026-10-01T060000Z-cursor-spike/workspace-build.json) identifies the separately dirty production checkout; this spike does not claim a production build or package pass.

Use the source/startup commands and browser recipe on the spike topic. Actions were performed through named controls and keyboard input; DOM and localStorage reads observed their effects. All data used here is synthetic. Source syntax checks covered `app.js`, `data.js`, `ui.js` and `server.mjs`. No package-manager installation or browser profile containing production credentials was used.

## Limits and follow-up

All selected final prototype scenarios passed. This is self-verification, not independent review. Chat is scripted; localStorage is not the production data folder; the Markdown preview is limited and editing is source-only. No real model, account, filesystem, full GFM, approvals catalog, schedule, audio, packaged Electron, clean-machine or VoiceOver validation is claimed. The native Cursor reference was inspected visually and through installed theme files; automated navigation was unavailable.

The browser date control rejected the driver's generic typing helper; inspection confirmed that no task had been submitted, and native segmented keyboard entry then saved the intended date. A screenshot taken immediately after navigation showed the preceding Notes frame; a later capture was inspected and confirmed Chat before it was retained. Browser-helper `navigator.modelContext` deprecation warnings were observed, without application exceptions.

The server was running at the first handoff, but the user subsequently reported it unavailable. The original tool-owned process had ended. The same server was restarted as the temporary macOS job `local.clarity.cursor-spike`; a separate subsequent tool invocation confirmed its live PID/parent, all five matching browser assets returning HTTP 200, and a visible loaded UI. [Recovery evidence](../../evidence/2026-10-01T060000Z-cursor-spike/server-recovery.json) records the correction. This verifies operation after the submitting command exits; logout/reboot persistence is not configured. Lifecycle and stop instructions are on the spike topic. Reset removes prototype edits only; it never touches production data.

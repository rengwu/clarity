# 3 October 2026 — Linear Music volume scaling

## Scope

**FEAT-music**, [D129](../../decisions/index.md#d129-linear-music-volume-scaling-3-october-2026): replace the shared 60 dB logarithmic slider mapping with direct `volume / 100` amplitude gain. Retain D124's fixed metadata normalization and D127's held-drag/key input, delayed-feedback protection and output-stage Spotify gain.

Selected checks cover the shared TypeScript mapping, native Spotify PCM path, controlled Navidrome Music UI, held input and a relocated signed package. These are fixture checks by the implementer, not listener confirmation or an independent review.

## Limits and follow-up

No live Spotify or Navidrome account, speaker recording, Bluetooth device or listener comparison was used. Direct amplitude scaling is intentional user-facing behavior, but actual perceived loudness also depends on the recording, normalization metadata and output hardware. The package exists in the external build cache and was not installed over `~/Applications/Clarity.app`.

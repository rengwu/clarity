## Question 2

```text
Round: Pi Durable spike: behavior to test
Question: When you approve a pending action, should the experimental assistant continue the rest of that task automatically?
Description (Markdown source):
Today Clarity queues a proposed action and returns control to the conversation. Applying it performs that action, but does not restart the assistant to finish dependent steps. A resumable approval would let a task pause for review and continue after Apply, including if Clarity restarted while waiting. Dismiss would resolve that action without performing it.
Recommendation: Test continuation after approval. It is a concrete benefit we can compare with the current queue, including restart, duplicate-click, rejection, and stale-data cases.
Options: Continue the task after approval / Keep the current queue; I send another message to continue
Selected: Continue the task after approval
Notes:
```

## Question 3

```text
Round: Pi Durable spike: behavior to test
Question: Should this spike test automatic summaries for long conversations?
Description (Markdown source):
Clarity currently sends recent complete turns and omits older turns from the model's active context while keeping the full saved transcript. Pi Durable can summarize older turns to retain more continuity. Summaries use extra model calls and can omit details; original messages would stay saved. This is within one conversation, not automatic memory across chats.
Recommendation: Include summaries and measure what survives. Use synthetic facts, decisions, and tool results to check continuity, omissions, and additional model usage against the current recent-turn approach.
Options: Test summaries alongside recovery and approvals / Focus on recovery and approvals; defer summaries
Selected: Focus on recovery and approvals; defer summaries
Notes:
```

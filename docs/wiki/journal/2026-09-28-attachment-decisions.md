# 28 September 2026 — Attachment scope and lifecycle

The user answered the attachment round. Recorded D93–D96: analyze text/code, supported images, and PDFs containing text; allow other types with a clear unsupported-analysis message; copy original files independently only below 30 MB, otherwise skip and notify; support drag-and-drop, file picker, and pasted images; and clean attachments after 90 days.

The user chose expiry rather than the assistant's proposed indefinite retention. No external original is a cleanup target. The attachment rule is distinct from Notes/Wiki Trash and does not delete conversations or module content.

Attachment date is the stated working assumption for the age origin. Cleanup during normal app operation/startup, derived-data removal, and expired-file presentation remain implementation proposals. Shared use as note/wiki assets needs an ownership rule before cleanup. Size-unit conventions, combined payload limits, and actual model/extraction compatibility remain to validate.

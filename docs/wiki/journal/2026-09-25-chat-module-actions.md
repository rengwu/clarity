# 25 September 2026 — Chat module actions

## User direction

The user confirmed that chat should act across all modules, giving examples: summarize news headlines, add or edit todos, add calendar events, read notes, read and summarize mail, retrieve bookmarks, search and play music, and alter the wiki.

## Changes

Recorded [D17](../decisions/index.md#d17-chat-across-all-modules-25-september-2026) and created [chat and module actions](../foundations/chat.md) to capture the shared behavior. Updated the home page, product vision, feature map, and integration notes. Resolved Q16's broad scope and retained detailed permissions and developer actions as open questions.

## Still open

Result presentation, operation-level permissions and confirmations, the remaining module actions, and the agent/model implementation remain undecided. The main sidebar is still a tentative navigation preference. Application implementation has not begun.

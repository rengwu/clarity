# 25 September 2026 — Mail reader

The user confirmed that Mail is just an inbox and message reader, with no composing or replying. They also want a link opening the corresponding email in a browser if possible. Recorded [D37](../decisions/index.md#d37-inbox-and-message-reader-25-september-2026), retaining Google connection and chat reading/summarization requirements.

Official Google references support the existence of Gmail message URLs, but the inspected API message schema does not supply a browser permalink. Reliable link construction and account targeting remain to be validated; sources and the limitation are recorded on the [Mail page](../features/mail.md#browser-link-feasibility). Local caching and offline behavior also remain open.

The next proposed discussion is a News headline list with browser-opened articles. This is not accepted scope. No application implementation or technology selection occurred.

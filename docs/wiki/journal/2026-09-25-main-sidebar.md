# 25 September 2026 — Main sidebar

## User direction

Asked how to reach the other modules from chat, the user replied: “probably a main sidebar for our main method of navigation”.

## Changes

Updated the home page, product vision, and Q15 to reflect this tentative preference. The chat opening screen and recent-chat sidebar remain accepted under [D16](../decisions/index.md#d16-chat-opening-screen-25-september-2026). No new accepted decision was added because the navigation preference was tentative.

## Still open

How module links and recent chats share the navigation, their grouping and order, and what chat can do with the modules remain open. No application UI has been built.

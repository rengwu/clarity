# 25 September 2026 — Chat opening screen

## User direction

When asked what Clarity should show first, the user specified a chat screen with recent chats in the sidebar.

## Changes

Recorded [D16](../decisions/index.md#d16-chat-opening-screen-25-september-2026), updated the home page and product vision, and added navigation and chat-capability questions. This gives the initial experience a concrete layout without selecting the full daily workflow or first-release scope.

## Still open

How users reach other modules, what chat can do with them, and whether launch starts a new conversation or resumes an existing one remain undecided. Application implementation has not begun.

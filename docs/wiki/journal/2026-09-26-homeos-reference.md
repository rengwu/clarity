# 26 September 2026 — HomeOS reference

The user shared Aaron Francis's X screenshot and asked what it is, expressing appreciation for its appearance. Added findings to the [reference register](../references/index.md#homeos-and-cloudflare-os-26-september-2026), without turning that reaction into a new UI or framework decision.

Read the post and a reply in Synara after ordinary web fetching failed. The screen identifies itself as HomeOS and shows Cloudflare OS account branding. Found Aaron's public Cloudflare OS fork and two HomeOS-named branches through GitHub's public API. This strongly supports a customized Cloudflare OS interpretation, but the exact saved-posts screen's source was not located.

Inspected the base README and frontend manifest: a Workers-based agent/gadget platform with a React/TypeScript/Tailwind frontend. Distinguished that cloud platform from Clarity's agreed local application and from an Electron desktop implementation. The screenshot supplies useful navigation and bookmark-card references, not proof of collector reliability or authorization to add its features.

Open: exact HomeOS source and UI components, X collection implementation, and deployment. No application setup or new product decision occurred.

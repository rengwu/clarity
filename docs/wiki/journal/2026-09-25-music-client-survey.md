# 25 September 2026 — Music client survey

The user requested a search for open-source projects that do lightweight Spotify or Navidrome playback well, naming Spotifast and Yuzic. This continues Music exploration without deciding which sources to implement.

Reviewed nine projects through public upstream documentation, repository and release metadata, and selected manifests/license files. Findings are consolidated on the existing [Music page](../features/music.md#open-source-client-survey-25-september-2026), keeping this topic together.

The assistant's shortlist is Spotifast for a desktop Spotify interface, Supersonic for lightweight Navidrome desktop playback, spotify-player for scriptable chat control, and EKO for a macOS local-file/Navidrome architecture. Yuzic remains a useful user-supplied interaction reference, with its current iPhone/iPad/Android focus explicitly recorded. ncspot, Psst, and Feishin offer additional comparisons; SonicLair is an older minimal design reference.

Resource claims are attributed, not treated as benchmarks. A small UI does not eliminate Spotify authentication work, audio dependencies, or macOS runtime constraints. No package was installed, client run, account connected, code copied, or app framework chosen. Still open: Music source priority, screen scope, and whether an existing player process would actually simplify the agreed experience.

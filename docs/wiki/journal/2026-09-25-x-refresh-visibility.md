# 25 September 2026 — X refresh visibility

The user accepted the proposed visible browser-assisted X bookmark refresh, adding that invisible background refresh would be better if possible. Recorded [D44](../decisions/index.md#d44-x-refresh-visibility-preference-25-september-2026). Visible refresh remains an acceptable fallback; read-only access and the lean rule remain in force.

The assistant proposes using the same collector for visible and hidden operation, with a visible page for sign-in or intervention. Hidden collection must be validated in the eventual desktop shell; no schedule, closed-app service, or browser technology is selected. If hiding the window requires substantial complexity, raise it and retain the accepted fallback.

The next proposed module discussion is Spotify playback inside Clarity versus control of an existing player. No application implementation or live X test occurred.

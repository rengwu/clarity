# 28 September 2026 — First-version behavior decisions

The user agreed to all four recommendations. Recorded D97–D100:

- Routine navigation, search, and reading proceed after site authorization without per-click confirmations. Consequential browser actions still require confirmation. D60 is explicitly partially superseded for this browser behavior; other module approvals remain unchanged.
- Use the current thread by default; retrieve earlier conversations when asked or referred to. No automatic cross-chat memory.
- Apply model/effort changes to the next message in the existing thread, preserving history.
- Deliberate embedding in Notes/Wiki creates a separate persistent module asset copy with a relative link. The chat copy expires after 90 days. Summarizing alone does not preserve the original.

Browser permission enforcement and grant scope/duration remain to design and validate. Codex subscription integration, local runtime packaging, model-input compatibility, and performance are engineering research tasks. Agreement settles product behavior and does not authorize application implementation or use of real accounts.

Updated topic pages, project guidance, the decision register, and the [resolved question round](../discussions/open-questions.md#next-first-version-question-round-28-september-2026). Earlier journals remain intact. Rebuilt the offline reader.
